Notes:
- PORT is injected automatically by Render.
- If DATABASE_URL is present, DB_HOST / DB_PORT / DB_NAME / DB_USER / DB_PASSWORD are not needed.
- GOOGLE_CLIENT_SECRET is not used by the current backend code, so you do not need to add it on Render unless you later implement a server-side OAuth flow that requires it.
- Replace DATABASE_URL with the PostgreSQL URL generated by Render. Do not use localhost in production.
- Replace FRONTEND_URL with your real frontend domain before pasting the file into Render Environment or Secret File.
